# 公开数据基线

pilot.json 是新安装的公开基线，保留原文件名以兼容已有启动与测试。它是持续补全的图谱，不是穷尽目录或所有全文均已核验的承诺。

可公开：身份、论文/专利版本关联、简短转述、原始链接与定位、不确定性及公共研究问题。access、readScope、disposition 标明实际读取/筛选范围。

不公开：检索回执及响应、原文、上传、私有路径、个人审阅/归档历史与观察。receipts / reviews 在种子中为空，observations 在本地生成。CI 检查这些边界与记录引用。

数据 PR 见[贡献指南](../CONTRIBUTING.md)。基线更新不会覆盖已有 SQLite，本地仍通过 atlas.py commit 更新。

`public/snapshot.json` 是在线版读取的公开发布物：由字段白名单从已整理的范围导出，可包含逐项审阅选定的公开资料综合观察，但不含作者、本地基准版本或私人工作流。发布过程见[说明](../docs/publication.md)。公开种子仍不复制私人观察历史。

computational-recall-2026-10-27.json 是历史召回回归基准，不是覆盖上限；research-coverage-2026-10-26.md 是对应日期的历史范围说明，数量不代表当前基线。

第三方材料权利归各自权利人。提交自己的短转述、标识及链接，不复制受限全文。
