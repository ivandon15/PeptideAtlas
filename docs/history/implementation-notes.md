## 明确边界

- 8 个分子是流程验证用的已收录记录，不能用来声称靶点全球分子总数或覆盖完整。
- 化学结构、全部编号中间体及部分专利实验仍有明确缺口，后续通过相同流程补齐。它们是需要继续研究的公开事实问题，不是自动生成的确定结论。
